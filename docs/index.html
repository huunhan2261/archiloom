Native Revit add-in · C# / .NET 8

Detailing, family housekeeping, Checking, and Camwalk.

ArchiLoom is a Revit ribbon tab of small, sharp tools for the work nobody schedules time for: renaming families in bulk, laying out detail items and sheet guides, renumbering a sheet set, and auditing tags, filters and view templates before you issue drawings. Then there's Camwalk — the one tool on this ribbon that isn't a dialog: a live, game-style fly-through camera for walking your 3D views. Every dialog follows one UI standard, so you learn the pattern once.

What's inside
The tab, panel by panel
Order on the ribbon follows ArchiLoomApp.OnStartup. Every button ships a tooltip with a short How-to. Click a tool card for a demo.
Family
Naming and cleanup for families and types — bulk edits with a preview you can trust.
4 tools
Family
Family Rename
→
Rename the family used by the selected family instance(s), applied to every type it owns.
Family Duplicate
→
Duplicate a family under a new name straight in the model and switch the selected instances over — no Save As, no reload.
Batch Rename
→
Rename Loadable Families, Loadable Family Types, System Family Types or Materials in bulk, PowerRename-style, with a live preview and an Excel round-trip.
Purge Family Params
→
List unused family parameters and delete them — ones still referenced elsewhere have their formula/value cleared instead and are kept.
Detailing
Detail items, line styles and sheet layouts — the repetitive half of documentation.
6 tools
Detailing
Detail Item Lookup
→
List every view containing the selected detail item type, with its sheet and instance count, to review one by one.
Detail Item From Selection
→
Turn selected detail lines, filled regions or detail components into a new detail item family, loaded straight back in.
Select 2D Elements
→
Rectangle-select only one kind of 2D element at a time — tags, detail items, filled regions or lines.
Quick Line Style
→
Remap the line style of selected lines/filled regions — group by current style, map each group to a new one in one pass.
Save Sheet Guide
→
Capture guide lines drawn on the active sheet and save them as a named preset for reuse on other sheets.
Apply Sheet Guide
→
Recreate a saved sheet guide as detail lines on target sheets, so new viewports line up across a set.
Checking
Tag, colour and section-box QA on the model in front of you — catch gaps before you issue drawings.
5 tools
Checking
Missing Tag Check
→
Find every element of a category — or your own saved rule — with no tag in the active view, from a dockable pane you can highlight from.
Highlight Annotations
→
Colour-override every instance of chosen annotation categories in the active view, so gaps stand out visually.
Color Swatch Highlight
→
Colour-override elements by a parameter value using saved, reusable rule sets — unique values, keywords or number ranges.
3D Crop From View
→
Match your Default 3D View's section box to the crop region of the active 2D view, for a quick QA look.
Parameter Excel Sync
→
Push and pull instance or type parameter values between Revit and Excel, filtered by category, workset, family or selection.
Auditing
Project-wide housekeeping — the filters, templates, sheet numbers and system definitions that pile up over a job.
4 tools
Auditing
Filter Audit
→
Audit every view filter in the project — where it's applied, its rules — then review, rename, edit or purge the unused ones.
View Template Audit
→
Audit every view template by how many views actually use it, then review, rename or purge the unused ones.
Sheet Numbering
→
Batch-renumber selected sheets — find/replace, prefix/suffix, increment, resequence and padding, all previewed before anything is written.
System Batch Rename
→
Batch rename line patterns, fill patterns, filters, view templates, view types or text note types — the project's system definitions.
Visual
The one tool on this ribbon that isn't a dialog — a live, game-style fly-through camera for your 3D views.
1 tool
Visual
Camwalk
→
Turn the active 3D camera view into a live fly-through with an on-screen HUD or WASD, and bookmark viewpoints as you go.
