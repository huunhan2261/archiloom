pyRevit extension · Revit 2021–2026

Detailing and family housekeeping, without the click marathon.

ArchiLoom is a Revit ribbon tab of small, sharp tools for the work nobody schedules time for: renaming families in bulk, syncing detail type data through Excel, laying out detail items, and reusing sheet layouts. Every dialog follows one UI standard, so you learn the pattern once.

Contributing
Issues and pull requests are welcome. New tools copy _TEMPLATE_window.xaml and _TEMPLATE_script.py, keep code and comments in English, and follow the shared style guide in lib/GUI/Resources/UI_GUIDELINE.md — a dialog that invents its own colour won't be merged.
