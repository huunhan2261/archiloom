# content/how-to/

Draft the "How to use" steps for each tool here first, one plain `.txt`
file per tool, one step per line. When a draft is ready, copy its lines
into that tool's `steps` array in the `TOOLS` list in `docs/index.html`
(this folder is just staging — the site reads `steps` from `TOOLS`
directly, not from these files).

Naming: kebab-case the tool name, matching the video file convention, e.g.
`batch-family-rename.txt`.

Two samples are included for the tools already in `TOOLS`, showing the
one-step-per-line format.
